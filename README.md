# מיני ארנה 🥊

**תשובה אחת היא ניחוש. טורניר הוא בחירה.** סקיל לקלוד שגורם לו לכתוב כמה גרסאות שונות באמת, לשפוט אותן כמו שופט קשוח, לתקן את החזקות ולהעמיד אותן שוב זו מול זו. מגיעה אליכם רק המנצחת.

הכול קורה בתוך תשובה אחת, בלי סוכני משנה ובלי כלים מיוחדים. לכן זה עובד **גם בצ'אט הרגיל של קלוד**, לא רק בקלוד קוד, ולוקח בדרך כלל פחות מדקה.

| מה הוא עושה | מה זה נותן לכם |
|---|---|
| שש גרסאות, כל אחת בגישה אחרת | יוצאים מהתשובה הצפויה הראשונה |
| שופט קשוח עם ציון מתוך 100 | כל גרסה מקבלת את החולשה הכי גדולה שלה, בפירוש |
| סיבוב תיקון ומשחק חוזר | החזקות משתפרות לפני שהן מגיעות אליכם |
| שלושה מצבים: מהיר, רגיל, עמוק | 4, 6 או 10 גרסאות, לפי כמה המשימה חשובה |
| איסור להמציא מספרים | אם חסר נתון אמיתי, תקבלו מקום ריק ולא המצאה |

## התקנה

### בצ'אט הרגיל של קלוד (claude.ai, גם בתוכנית החינמית)

1. הורידו את הקובץ `mini-arena.zip` מעמוד ה־[Releases](https://github.com/Brain-ai-biz/mini-arena/releases/latest).
2. בהגדרות של קלוד, תחת Capabilities, הדליקו את Code execution and file creation.
3. היכנסו ל־Customize ואז Skills, לחצו על הפלוס, בחרו Upload skill והעלו את הקובץ.

### בקלוד קוד

הדביקו את זה לקלוד קוד:

```
https://github.com/Brain-ai-biz/mini-arena
תתקין את הסקיל הזה ותוודא שהוא עובד.
```

או ידנית:

```bash
git clone https://github.com/Brain-ai-biz/mini-arena.git
cp -r mini-arena/mini-arena ~/.claude/skills/
```

## איך משתמשים

כותבים בצ'אט "תעשה זירה", ואחרי זה את המשימה:

```
תעשה זירה: כותרת לדף ההרשמה לסדנה שלי, לקהל של בעלי עסקים קטנים
```

רוצים מהר יותר? "זירה מהירה". משהו חשוב באמת? "זירה עמוקה". רוצים לראות את כל הקרב ולא רק את המנצחת? בקשו "תראה לי את הקרב".

הסקיל נדלק גם לבד כשאתם לא מרוצים מתשובה ומבקשים שוב.
